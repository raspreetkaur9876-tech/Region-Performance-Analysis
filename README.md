# Region Performance Analysis

## Project Overview
This project compares sales and profit across four regions using the Superstore dataset. It uses Microsoft Excel to summarize regional performance, rank regions, and visualize sales differences with a bar chart.

## Objectives
- Compare total sales across regions.
- Analyze total profit by region.
- Rank regions based on sales and profit.
- Create a bar chart for regional sales comparison.

## Tools Used
- Microsoft Excel
- Superstore Dataset

## Project Features
- Region-wise sales summary
- Region-wise profit summary
- Sales ranking and profit ranking
- Bar chart showing regional sales performance
- Key insights based on the results

## Key Findings
- **West:** Highest total sales.
- **South:** Lowest total sales.
- **Central:** Highest total profit.
- **South:** Lowest total profit.

## Skills Learned
- Data aggregation using SUMIF
- Ranking using RANK.EQ
- Data organization and comparison
- Excel charts and visualization
- Basic data analysis and interpretation

## Project Files
- `Region_Performance.xlsx` — Excel workbook containing the regional summary, rankings, chart, and insights.

## Conclusion
This project helped me practice data analysis in Excel by comparing sales and profit across regions. The summary table, rankings, and bar chart make it easier to understand regional performance.
